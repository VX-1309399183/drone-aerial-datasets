| 🖼️ 样本总量   | 768组RGB可见光+红外图像配对数据                              |

这套多模态数据集专门服务于建筑外立面智能化巡检、结构健康监测方向的语义分割算法研究。数据集由严格配准的可见光与红外图像成对组成，两种影像一一对应，实现像素级对齐，非常适合训练多模态融合网络。

✨多视角解读
🔹算法研发视角
适合搭建多模态融合分割模型，对比单RGB、单红外、双模态融合方案的精度差异，是建筑病害方向多模态算法实验的优质底座。
🔹工程落地视角
贴合无人机、手持巡检设备同步采集可见光+红外热图的真实业务场景，训练出来的模型可迁移至外立面自动巡检项目。
🔹科研论文视角
划分方式规避序列帧泄露，标注规范、双模态严格对齐，实验结果可信度高，适合基础设施计算机视觉方向课题研究。
🔹教学毕设视角
可以学习多模态图像配准、语义分割网络搭建、红外病害识别整套流程，选题方向新颖。
